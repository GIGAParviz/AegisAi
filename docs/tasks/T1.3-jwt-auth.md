## هدف
چرخه کامل توکن: ثبت نام با هش پسورد، login با صدور access+refresh، و refresh برای توکن جدید.

## گام‌ها
1. app/core/security.py: hash_password/verify_password (passlib با pbkdf2_sha256 یا argon2) + create/decode توکن با pyjwt و settings.jwt_secret.
2. app/api/auth.py: POST /auth/register (201 + جلوگیری از duplicate email با 409)، POST /auth/login (401 برای پسورد غلط)، POST /auth/refresh.
3. tests/test_auth.py: مسیر خوشحال register→login→refresh + 401 پسورد غلط + 401 توکن منقضی (با monkeypatch روی expire).
4. router را در main.py ثبت کن و commit.

## فایل‌ها
- `app/core/security.py`
- `app/api/auth.py`
- `tests/test_auth.py`
- `app/main.py`
