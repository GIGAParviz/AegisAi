## هدف
هر push و PR به صورت خودکار lint+test شود تا کیفیت از روز ۲ تضمین شود.

## گام‌ها
1. فایل .github/workflows/ci.yml بساز: on: [push, pull_request] روی ubuntu-latest و Python 3.11.
2. مراحل: checkout، setup-python، pip install -e ".[dev]"، ruff check .، pytest -q.
3. push کن و در تب Actions سبز شدن workflow را ببین.
