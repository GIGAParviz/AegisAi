## هدف
ترکیب تاریخچه (Redis) + اسناد بازیابی شده (Qdrant) + حقایق DB در یک payload مستند و کوتاه با citation.

## گام‌ها
1. app/services/context_builder.py: build(query, session_id, user) -> ContextPayload.
2. بخش ها: history (آخرین N پیام از Redis)، sources (top-k از hybrid_search با شماره [1]..[k])، facts (از DB).
3. سیاست برش: بودجه توکنی کل (settings.max_context_tokens)؛ حذف از قدیمی ترین history و پایین ترین rank منابع.
4. tests/test_context_builder.py: ترتیب بخش ها، citation ها، و برش با بودجه کوچک.
5. commit.
