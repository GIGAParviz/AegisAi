## گام‌ها
1. app/db/models/user.py: id (uuid)، email (unique)، hashed_password، role (enum: admin/user/agent)، is_active، created_at.
2. alembic init migrations؛ env.py را با URL از settings تنظیم کن و target_metadata=Base.metadata.
3. اولین revision را autogenerate کن و `alembic upgrade head` را روی dev اجرا کن.
4. tests: roundtrip ساخت/خواندن User + test که migration از صفر اجرا می شود (sqlite فایل موقت).
5. commit.
